Development build of **Amped2-Recomp** from the `dev/all` branch of this fork: a native PC port of **Amped 2
(original Xbox, 2003)**, made by statically recompiling the game's Xbox code to C with
[xboxrecomp](https://github.com/sp00nznet/xboxrecomp). No emulator.

This is a **pre-release**: everything on top of upstream v0.2.0 that is not merged there yet – the **NTSC-U
disc**, **Windows with the Vulkan renderer** (playable now), the game's **native 720p widescreen** extended to
21:9, about **4x faster rendering**, and fixes for **audio freezes and distorted music**. Expect rough edges.

> ⚠️ **No game files included.** You need your own, legally obtained copy of Amped 2 for the Xbox. This package is
> built for the **NTSC-U / North America version** (title ID 4D530041, `default.xbe` SHA-1
> `5f432b86775b7b334212a3bc09d2063f670865b7`); with another version it stops and says which one it needs. Never
> share game files.

## Getting started

1. Download `Amped2-Recomp-dev-20261103-ntsc-u-windows-x86_64.zip` below and unpack it.
2. Put the extracted disc files into the package's `game_files/` folder (`default.xbe` directly in it, not in a
   subfolder), or point `game_dir` in `settings.ini` at them – see the package's `README.txt` and the
   [v0.2.0 notes](https://github.com/bertibertig/Amped2-Recomp/releases/tag/v0.2.0) for making and extracting a
   disc image.
3. Double-click `run.bat`, or right-click `run.ps1` → *Run with PowerShell*. Both write the console output to
   `run.log`.

Needs Windows 10 or 11 (x86-64) and a current GPU driver with Vulkan 1.3. There is no Linux package in this
pre-release (build it yourself, see below).

## What's new since v0.2.0

### New features

- **NTSC-U disc support** next to PAL (per-build addresses and seeds; a `default.xbe` from the other version is
  refused with a message naming the one that is needed).
- **Windows with the Vulkan renderer**: the same renderer and graphics settings as on Linux; saves and the custom
  soundtrack work, the game is found next to the exe or via `game_dir`, and the window position is remembered.
- **Native HD widescreen**: the game's own 720p mode (16:9 camera and HUD), extended to 21:9; 16:10 shows it with
  thin bars. Menus with their own frame are pillarboxed at 21:9, other menus span the screen.
- **Smoother frame pacing** at "display refresh": frames are now spaced one refresh apart instead of arriving in
  bursts (7 frames 5 ms apart, then a 20 ms gap), which looked like judder at 110–145 fps.

### Improvements

- About **4x faster rendering** (a Vulkan pipeline per combiner program built in the background, two frames in
  flight, cheaper combiner registers): menus 60+ fps and rides well above 100 fps at 2x / 21:9.
- Widescreen: off-screen HUD elements hidden, fades full width, the boarder's face correct after a ride, coins and
  icons on challenge cards and the results screen in place at 21:9.
- The title screen's attract mode no longer closes the game.

### Bug fixes

- **Audio and picture freezes of ~0.5 s during rides** are gone, and the **loud, distorted music** they caused:
  the game's sound code could wait on the audio interrupt while holding it off.
- Results screen lag after a ride.
- Boarder profiles listed twice on Windows.

## Platform status

- **Windows 11** (NVIDIA RTX 4070 SUPER, 3440x1440 at 144 Hz, borderless, 2x / 21:9, unlocked at display refresh):
  played from the NTSC-U disc – menus, career rides, 13-minute sessions without a freeze or crash.
- **Linux / Steam Deck**: the code builds and runs there (upstream's platform), but no package and no test of this
  build.
- **PAL disc**: supported by the code, but this package is the NTSC-U build.

## Known issues

- Now and then a short glitch in the music was heard; it does not show up as a dropout in the audio the game
  produces – under investigation.
- Heavy ride sections run at about 115–130 fps at 2x / 21:9 (CPU-bound), so frame times are less even there.
- Draw distance is the original game's.
- See also the known issues of [v0.2.0](https://github.com/bertibertig/Amped2-Recomp/releases/tag/v0.2.0).

Please report bugs at [Issues](https://github.com/mpusch88/Amped2-Recomp/issues) with `run.log` from the package
folder.

## Building it yourself

See the README: the pipeline needs your own `default.xbe`, then `scripts/build.sh` (Linux) or the native Windows
build (`build-win`, Git Bash + llvm-mingw/MinGW).
